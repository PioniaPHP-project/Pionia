# Sample App — API Reference

> Generated by `pionia api:docs`. Interactive docs: `/docs` (debug) or `index.html` after `api:docs --ui`.

All actions use **Moonlight dispatch** — send JSON to a versioned base path:

```json
{ "service": "<alias>", "action": "<action>", "...params" }
```

**Response envelope:** `returnCode`, `returnMessage`, `returnData`, `extraData`.

---

### `create_auth`

Creates an auth record

#### Request

| | |
|---|---|
| **POST** | `/api/v1` |
| `service` | `auth` |
| `action` | `create_auth` |
| Auth | `required` |

**Body parameters**

| Field | Type | Description |
|-------|------|-------------|
| `username` | string | Login name |
| `password` | string | Secret |

**Example**

```http
POST /api/v1 HTTP/1.1
Content-Type: application/json

{"service":"auth","action":"create_auth","username":"demo","password":"secret"}
```

#### Response

```json
{
    "returnCode": 0,
    "returnMessage": "Success",
    "returnData": {},
    "extraData": null
}
```
